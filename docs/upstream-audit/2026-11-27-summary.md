## 已落地的主要修复

后端（认证、审计与数据一致性）：

- **审计**：审计路径过滤同样命中直挂的 `/openai` 等路由（`d065a7048`）；审计在 METADATA/REQUEST 级别也记录响应状态码，被拒绝请求与成功请求可区分（`89ecb59a2`）。
- **认证**：OIDC 提供方用 client secret 对 ID token 做 HS256 签名时也能登录（`3904bd604`）；时区未变化时不再写库并触发 `USER_UPDATED`（`c35321f9a`）。
- **授权**：移动文件夹只接受本人拥有的父文件夹（`d64df861a`）；`ENABLE_ADMIN_CHAT_ACCESS` 关闭时管理员也不再能凭 `meta.internal` 读取他人的 internal 会话（`612336066`）；组分享列表在 `share=false` 时仍按成员关系过滤（`d3e87f8b1`）。上游给单条消息更新与消息事件加的“只改聊天属主自己的消息”守卫（`a8e7ac398`）只服务于允许成员共同回复的共享聊天；Pure 的共享聊天是只读快照、消息只能由属主写入，且消息行不落 `user_id`，该守卫在本地是等价空操作，因此不引入。
- **删除流程**：删除文件夹或全部聊天时先停止其流式回复与后台任务，避免请求与容量泄漏（`cdf38c4a7`）；删除用户前停止其所有聊天中的运行任务（`1c2c3e794`）；删除带聊天的文件夹时一并清理残留的 internal 子会话（`1fcfc8a5c`）；Postgres 下删除聊天先锁 Chat 行，避免与并发写入互相阻塞导致删除静默失败（`4ca96cffc`）。
- **性能**：侧栏/文件夹文件列表改为每文件夹一次小查询确认所有权，不再逐个完整读取文件行（`4abf416f9`）；Unarchive All 只读聊天的 `id` 与 `meta`，不再加载整段历史（`991bb4609`；导出与归档列表在 Pure 本就是单查询）；上下文压缩关闭时跳过第二次整段会话读取（`3a7291ba7`）；`get_message_by_id_and_message_id` 改为单行读取（`0f71ee15a`）。
- **聊天流程**：停止生成时保存的回复带上模型已上报的 token 用量，避免下一轮把上下文估大而提前压缩（`d8ba9d553`）；Continue 恢复回复时清空旧 error 与 done 状态（`d3ddbf715`）；空聊天也能拿到上下文压缩阈值（`4b4ad49a7`）。
- **OpenAI 兼容**：Responses API 连接把系统提示始终作为 developer 消息发送，自定义模型 id 下也能命中提示缓存（`5d1c7d39d`）；vLLM/OpenRouter 增加顶层 `reasoning` 字段的推理回放格式（`a78a9663b`）；Responses 工具轮次回放加密推理项，并在去敏时剔除 `encrypted_content`（`c1f3b6fd1`）。
- **数据兼容**：`done` 为空的行（提问、导入回复）不再被读成“未完成”（`d8c500a8d`）；账户设置拒绝晚于今天的出生日期（`c56ba4e75`）。
- **升级与日志**：迁移入口按 `GLOBAL_LOG_LEVEL` 设置 root 级别，大表搬迁不再看似卡死（`893584700`）。
- **Redis（opt-in）**：客户端 8.0.1 → 8.2.0，同步 `requirements-redis.txt`、`pyproject.toml` 与 `uv.lock`，不新增依赖（`6b1d890ff`）。

前端（聊天、设置与通用控件）：

- **无障碍与焦点**：hover 控件改为键盘焦点/展开菜单时显示，鼠标点击不再常驻（`3bad55fadb`）；删除列表条目后焦点落到相邻行（归档聊天、分组、用户、Workspace 模型、Prompts，`34888d690`）；文件夹的 goto 使用 `keepFocus`；模型编辑器的“默认启用”开关 aria-label 加分区前缀（`7d1f81562`）。
- **性能**：运行中状态文字的 shimmer 改为 GPU transform 动画（`2a534ab1b`）；工具调用动画不再每帧重排整页（`01aae7268`）；highlight.js 按需加载（`3b6e0855d`）；Workspace 模型列表不再等待未使用的请求（`41652d4a0`）；Admin Settings 的 Models 与 Interface 首批请求并行（`d59de004b`、`ed1c7e45d`）；模型编辑器不再等待语音/工具列表（`306f9be78`）；dayjs 语言包按需加载（`b5a9aead8`）；回复完成后的侧栏刷新不再阻塞回复（`06b47d455`）。
- **缺陷修复**：`/status` 在回复以工具结果结尾时上下文估算偏低（`44ca4e78f`）；复制含公式的回复粘贴为 TeX 源码（`d22b3f303`）；关闭 Remember Dismissal 后已忽略横幅恢复显示（`4fc317b3d`）；Continue 后错误框残留（`d3ddbf715`）；Provider 多行错误消息保留换行（`e2ae06477`）；全选后按 Enter 不再报 RangeError（`e861fde7c`）；触屏点预览图按钮与双指缩放卡死（`9aafbf4f5`、`cf100751e`）；拖动外部时下拉正确收起（`bb98273f9`）；格式化工具条在焦点离开编辑器后收起（`0c336e072`）；PDF 导出时展开代码块并关闭多模型标签视图（`aa3f714c2`）；子菜单不再超出视口（`acdb7b503`）。
- **聊天状态**：等待工具调用（`function_call status=pending`）的回复不再被误标为 done（`847252425`、`d8411aa52`）；Send now 的回复在本页未加载时结束时不再留下空回复与 Stop（`24af96520`）；`/` 菜单打开期间 Compact/Fork 及时解除置灰（`c5e37298b`、`f80a4f782`）；刷新时仍在 uploading 的附件不再卡死并阻塞发送（`a094c546e`）。
- **设置与连接**：连接表单只在 bearer 认证时要求 API Key（`26f85aa22`）；已禁用连接的半透明遮罩改为整行 `opacity-50`（`a667c3176`）；保存模型的新头像后无需刷新页面（`fef778d19`）。
- **路由页**：`+error.svelte` 按上游最终形态重写（状态码 + 状态行、drag-region、logo），使用 Pure 的 gray 令牌（`7476d6e7f`、`2ca21e5f2`）。
