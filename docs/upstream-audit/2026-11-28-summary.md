## 已移植（8 条 scoped 记录 / 6 个提交）

- **`278342b867`（backend-runtime，adopt）** — 系统消息被拆成多个 text 块时，`merge_system_messages` 原只取第一块、`update_message_content` 会向每个块重复追加内容。改为拼接全部 text 块、只向首/末块追加一次。`backend/open_webui/utils/misc.py`。
- **`0e5eb45c09`（backend-runtime，adopt）** — 流式过程只捕获 `CancelledError`，模型连接中途断开时已流出的文本不会落库。新增 `except Exception` 分支：保存 `incomplete` 输出、清理响应流后再抛出。`backend/open_webui/utils/middleware.py`。
- **`f725d5c759`（backend-runtime，adopt）** — 新增 `MODEL_CONNECTION_CLOSED` 文案，在聊天 payload 的 `except` 中把 `aiohttp.ClientPayloadError` 替换为可读提示。`backend/open_webui/constants.py`、`main.py`。
- **`1e68fa8d18`（backend-api / backend-runtime，adapt）** — 只取 openai 部分：`OPENAI_MODELS` 由进程内普通 dict 改为 `RedisDict`（`cache_set_signature=True`），删除连接时 `.clear()`、拉取后用 `.set()`，避免多 worker 下一个 worker 清缓存后其他 worker 仍持旧 `urlIdx` 导致 model not found。ollama hunk 丢弃。`socket/main.py`、`main.py`、`routers/openai.py`。
- **`301ae2cf7d`（frontend-chat / frontend-ui，adapt）** — 只取「文件夹表单保存成功才关闭」契约：`FolderModal` 按 `onSubmit` 返回值决定是否关闭，`Sidebar`/`RecursiveFolder`/`FolderTitle` 的成功分支 `return true`，并删除 `Sidebar.createFolder` 里会留下幽灵文件夹的临时占位逻辑。machines 的 OpenDirectory 与滚轮 hunk 丢弃。
- **`a8399f68fb`（frontend-chat，adopt）** — `buildReasoningToken` 对「已结束但没有文本」的 reasoning 块返回 `null`，不再渲染空的「Thought for N seconds」。`structuredOutput.ts`。
